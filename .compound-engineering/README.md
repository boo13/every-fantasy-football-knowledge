# Compound Engineering integration

The configuration places durable learning under `docs/solutions/`. The plugin itself is not vendored or installed by this repo. Use an independently installed Compound Engineering plugin and follow [the public-only runbook](../docs/weekly-runbook.md).

Capture one established learning per `ce-compound` run; refresh affected learnings with `ce-compound-refresh`. Use non-interactive lightweight capture for unattended work so unrelated personal session history is not inspected. The repository's privacy boundary overrides any plugin suggestion to mine external/private context.
