# Knowledge library

Use the smallest set of documents that answers the question. Evergreen guides explain reasoning; dated research supplies current context; raw observations preserve evidence.

## Learn the game

- [Football and fantasy in one sitting](football-and-fantasy.md): positions, scoring, and the basic weekly cycle.
- [Glossary](glossary.md): terminology without assuming prior football knowledge.
- [Strategy handbook](handbook/README.md): twelve focused guides with hypothetical worked examples and conditional decision tables.

| Task | Start with | Add |
| --- | --- | --- |
| Understand the league format | [Scoring and replacement value](handbook/scoring-and-formats.md) | Actual settings supplied privately |
| Prepare for a draft | [Snake draft](handbook/snake-drafting.md) or [auction draft](handbook/auction-drafting.md) | [Current-season reference](season-2026/) and live format-matched ADP/projections |
| Evaluate a player | [Position evaluation](handbook/position-evaluation.md) and [opportunity metrics](handbook/opportunity-and-uncertainty.md) | [Current evidence](../context/CURRENT.md), [latest research](../research/LATEST.md) |
| Research waiver options | [Waivers and FAAB](handbook/waivers-and-faab.md) | Public role/availability evidence and privately supplied options |
| Set a lineup | [Lineup and schedule management](handbook/lineup-and-schedule-management.md) | Live official availability, eligibility and lock times |
| Interpret injury or reserve status | [Availability and injury reports](handbook/availability-and-injury-reports.md) | Official report stage, publication time and subsequent updates |
