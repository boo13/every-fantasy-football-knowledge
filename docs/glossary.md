# Fantasy glossary

General vocabulary; league configuration always overrides an example. Reviewed 2026-08-31.

| Term | Meaning |
| --- | --- |
| ADP | Average draft position: where a player is typically selected in a particular sample, platform and format |
| Auction / salary-cap draft | Managers allocate a draft budget to bid on players |
| Bye | A week when a real NFL team has no scheduled game |
| Ceiling / floor | Informal descriptions of upside/downside; not guaranteed boundaries |
| FAAB | A limited waiver acquisition budget used for bids; often blind, subject to league rules |
| Free agent | An available player who may be added under the league's rules |
| Handcuff | A backup rostered partly for upside if the lead player becomes unavailable |
| IR slot | A fantasy roster slot with platform-specific eligibility; not identical to NFL injured reserve |
| PPR / half-PPR | One / half a fantasy point per reception, before other scoring categories |
| Redraft / keeper / dynasty | Rosters reset / partly persist / largely persist between seasons |
| Snake draft | Draft order reverses each round |
| Streaming | Rotating a roster spot among available players based on weekly options |
| Superflex | A flexible lineup slot that allows a quarterback as well as other eligible positions |
| Waivers | A process for allocating players when multiple managers may want them |

Fantasy terminology references: [Sleeper beginner guide](https://sleeper.com/blog/what-is-fantasy-football/), [NFL fantasy FAQ](https://www.nfl.com/news/faq-for-fantasy-football-beginners-09000d5d808cbbec). These compact definitions are not a statement of any league's rules.

## Reading player opportunity

| Term | Meaning |
| --- | --- |
| Carry | A rushing attempt |
| Target | A pass directed toward a receiver; not necessarily caught |
| Reception | A completed catch credited to the receiver |
| Snap share | Share of team offensive snaps on which a player participated; not the same as touches |
| Route participation | Routes run relative to a stated passing-play denominator; verify provider definition |
| Target share | Player targets divided by team targets over the same sample |
| Red zone | The area within the opponent's 20-yard line |
| Game script | The evolving score/time situation and its possible effect on play selection |
| Regression | Extreme observed performance moving toward a more sustainable expectation; direction and amount are uncertain |

For dataset-specific definitions use the [nflverse player-stat dictionary](https://nflreadr.nflverse.com/articles/dictionary_player_stats.html); do not mix denominators or providers without checking them. Snap/route/red-zone data are not collected by the current script.
