# Fantasy glossary

Reviewed 2026-08-31. League configuration and provider definitions override generic shorthand. These definitions do not establish anyone's actual rules. For worked examples, use the [handbook](handbook/README.md).

## The sport and its positions

| Term | Meaning |
| --- | --- |
| Down | A period from the ball becoming live to dead; “first down” starts a new offensive series |
| Line of scrimmage | The line associated with the ball's location before the play |
| Snap | The action starting a play; also used to count plays participated in |
| Drive | A sequence of plays during a team's possession |
| Touchdown / TD | Reaching the opponent's end zone with possession; six real-game points |
| Field goal / FG | A kick through the goalposts for three real-game points |
| Extra point / PAT | The kick option after a touchdown |
| Two-point conversion | The non-kick scoring option after a touchdown |
| QB | Quarterback |
| RB | Running back |
| WR | Wide receiver |
| TE | Tight end |
| K | Kicker |
| D/ST / DEF | Team defense, usually including configured special-teams scoring |
| IDP | Individual defensive player, distinct from a team D/ST |
| DL / LB / DB | Defensive line / linebacker / defensive back; fantasy eligibility varies |
| Sack | Tackling a passer behind the line of scrimmage on an applicable passing play |
| Interception / INT | A defender catches the opponent's pass |
| Fumble | Loss of control by a player holding the ball, excluding a legal pass/handoff/kick; the opponent need not recover it |
| Fumble lost | A fumble resulting in the opponent gaining possession |
| Pick-six | An interception returned for a touchdown |
| Red zone | The area inside the opponent's 20-yard line |
| Bye | A week in which an NFL team has no scheduled game |

Scoring and possession definitions: [2026 NFL rulebook, Rules 3 and 11 (PDF)](https://static.www.nfl.com/image/upload/fl_attachment/league/tqivdkzt9mu6wdgsh1ku.pdf). Position and field vocabulary: [NFL football terms](https://operations.nfl.com/rules-officiating/nfl-football-basics/football-terms). Real-game points are not automatically the fantasy awards for the same play. See [position evaluation](handbook/position-evaluation.md).

## Formats, lineups, and rosters

| Term | Meaning |
| --- | --- |
| PPR / half-PPR / non-PPR | One / half / no point per reception, before other categories |
| TE premium | Additional TE-specific scoring, commonly a reception bonus; confirm the exact rule |
| FLEX | A slot accepting multiple eligible positions; commonly RB/WR/TE, but check |
| Superflex | A flexible slot that also permits a QB; not a requirement to start a QB there |
| Two-QB | A lineup requiring two QB slots; distinct from superflex eligibility |
| Bench | Rostered players outside the chosen starting lineup |
| Lineup lock | The deadline after which a player or lineup can no longer be changed under the rules |
| Best ball | The format selects the best eligible lineup from a roster's realized scores |
| Auto-sub | An optional platform-specific replacement mechanism; not ordinary bench scoring |
| IR slot | A fantasy reserve slot with configurable eligibility; not identical to NFL injured reserve |
| Taxi squad | Additional developmental roster slots governed by eligibility and promotion rules |
| Redraft | Rosters reset for a new season |
| Keeper | A defined number of players may be retained, possibly at a cost |
| Dynasty | An ongoing retained roster across seasons, subject to the league's cutdowns/rules |
| Head-to-head | Competition against a scheduled fantasy opponent for a scoring period |
| Total points | A competition based on accumulated scoring rather than only matchup wins |
| PF / PA | Fantasy points for / against; the time period and platform display matter |
| ROS | Rest of season; state the included weeks and fantasy playoffs |

Format references: [league types](https://support.sleeper.com/en/articles/3537396-league-types-formats), [Best Ball](https://support.sleeper.com/en/articles/4100708-do-you-offer-best-ball), and [AutoSubs](https://support.sleeper.com/en/articles/9731991-how-does-player-autosubs-work). Read [scoring and formats](handbook/scoring-and-formats.md) and [lineup management](handbook/lineup-and-schedule-management.md) before applying these labels.

## Drafts, acquisitions, and roster strategy

| Term | Meaning |
| --- | --- |
| ADP | Average draft position in a specific dated sample, platform, and format; not a projection |
| Snake draft | Selection order reverses between rounds |
| Linear draft | The same selection order repeats each round, before trades or manual changes |
| Auction / salary-cap draft | Players are allocated by bidding from a configured draft-credit budget |
| Nomination | Choosing the next player to be offered for bidding |
| Tier | An analytical grouping of players with similar estimated value or uncertainty |
| Replacement level | The contribution expected from a realistic available alternative |
| Value above replacement | A player's projected contribution minus that replacement baseline |
| Positional scarcity | Limited suitable alternatives relative to lineup demand |
| Waivers | A claim process that temporarily holds players before allocating them |
| Rolling priority | Successful claims move the claimant down a continuing priority order |
| Reverse-standings priority | Priority is reset using the standings under the league's rules |
| FAAB | Free-agent acquisition budget: limited waiver credits, distinct from draft credits unless linked |
| Free agent | A player available for acquisition under the league's current rules |
| Streaming | Rotating players through a roster role based on weekly options |
| Stash | A rostered player held for possible future rather than immediate use |
| Handcuff | A backup held partly for the possibility of increased work if a lead player is unavailable |
| Stack | Rostering related scorers, often a QB and receiver; not the same as stacking scoring categories |
| Zero RB / hero RB / robust RB | Shorthand for little / one anchor / multiple early investments at RB; not fixed universal rules |
| Rookie draft | A draft restricted to incoming players as defined by the league |
| Keeper cost | The pick, credits, or other resource surrendered to retain a player |

Platform mechanics: [draft types](https://support.sleeper.com/en/articles/9701062-what-draft-types-are-supported), [waiver types](https://support.sleeper.com/en/articles/1876041-what-types-of-waivers-do-you-support), and [FAAB](https://support.sleeper.com/en/articles/1876040-how-does-faab-bidding-work). Analytical terms describe methods, not proven advantages. See [snake drafts](handbook/snake-drafting.md), [auction drafts](handbook/auction-drafting.md), [waivers](handbook/waivers-and-faab.md), and [trades](handbook/trade-evaluation.md).

## Opportunity and statistical interpretation

| Term | Meaning |
| --- | --- |
| Carry | Rushing attempt |
| Target | Pass directed toward a receiver; not necessarily caught |
| Reception | Completed catch credited to the receiver |
| Touch | In ordinary offensive usage, a carry or reception; targets are not all touches |
| Dropback | Passing-play action; provider filters determine inclusion of sacks/scrambles |
| Route | A receiving path run on a passing play; not every offensive snap is a route |
| Snap share | Player snaps divided by relevant team snaps over a matching sample |
| Route participation | Routes relative to a stated passing-play denominator; verify provider definition |
| Target share | Player targets / team targets over matching games and scope |
| TPRR / YPRR | Targets per route run / receiving yards per route run; requires actual route counts |
| Air yards | Distance of a target relative to the line of scrimmage, including qualifying incompletions |
| aDOT | Average depth of target; check air-yard and target filters |
| YAC | Yards gained after the catch |
| WOPR | Provider-defined weighted opportunity index combining target and air-yard shares; not a percentage |
| xFP | Model-estimated fantasy value of opportunities under a specified scoring basis |
| EPA | Change in modeled real-football expected points on a play; not fantasy points |
| CPOE | Completion percentage over the model's expectation |
| PROE / pass OE | Pass/dropback rate relative to model expectation; definitions vary |
| Game script | Score and time context and its possible influence on play selection |
| Floor / ceiling | Informal downside/upside labels; not guaranteed bounds or defined quantiles unless specified |
| Regression | Revising an extreme observed rate toward an estimated sustainable rate; not an outcome that is owed |
| Sample size | Number of relevant observations, such as games, targets, or routes; state which |
| Denominator | The quantity a rate divides by; a changed denominator can change its meaning |
| Opportunity cost | The useful alternative forgone by choosing a player, bid, or roster hold |

Provider definitions: [nflverse player-stat dictionary](https://nflreadr.nflverse.com/articles/dictionary_player_stats.html), [nflfastR fields](https://nflfastr.com/reference/fast_scraper.html), and [ffopportunity](https://ffopportunity.ffverse.com/). These are not a claim that every metric exists in this repository. The [metrics guide](handbook/opportunity-and-uncertainty.md) explains denominators, aggregation, data gaps, and model limits.

For this project's evidence vocabulary—observation, evidence cutoff, hypothesis, durable lesson, and correction—use [CONCEPTS.md](../CONCEPTS.md).
